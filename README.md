# YouTube 双语直播字幕 v2.0

面向**无 CC 字幕外语直播**的 Chrome 实时同传扩展。采用 **WebSocket 流式语音识别 + 上下文 SSE 流式翻译**，直接在原 YouTube 播放器上低延迟显示双语字幕（支持全屏、拖动位置、调字号、历史记录面板）。

## v2.0 核心重构与改进

相比 v1.2.0 的「2.2 秒硬切 WAV + 新标签页录屏缓冲 8 秒」，v2.0 进行了全面重构：

| 维度 | v1.2.0 旧架构 | v2.0 新架构 |
| --- | --- | --- |
| 语音识别 | 每 2.2 秒硬切 48kHz WAV 轮询 HTTP | **WebSocket 实时流式 ASR**（Deepgram Nova-3 / OpenAI Realtime），16kHz/24kHz 实时重采样推流，边说边出字 |
| 断句与延迟 | 经常切碎单词，单句延迟 4–8 秒 | 服务端 VAD + 智能标点断句，**首字延迟约 0.5–1.5 秒** |
| 翻译质量 | 孤立碎片翻译，语序与指代混乱 | **4 句滑动上下文窗口 + SSE 流式输出**，术语、人称连贯，译文逐字浮现 |
| 画面与性能 | 另开标签页录整个网页再裁剪，画质糊、耗 CPU | **仅捕获音频**，原 YouTube 最高画质播放，零视频转码开销 |
| 字幕交互 | 固定位置、最长停留 2.6 秒一闪而过 | **双行滚动同传**、悬停工具栏（上下拖动、`A-`/`A+` 字号、侧边历史记录与一键复制、静音自动淡出） |

## 支持的服务组合

识别引擎与翻译引擎解耦，可按预算和延迟需求自由搭配：

| 环节 | 支持服务 | 模型 / 协议 | 特点 |
| --- | --- | --- | --- |
| **流式语音识别** | **Deepgram（推荐）** | `nova-3` (`wss://api.deepgram.com/v1/listen`) | 极低延迟，原生 `multi` 多语种支持，免费注册即送额度 |
| **流式语音识别** | **OpenAI Realtime** | `gpt-4o-mini-transcribe` (`wss://api.openai.com/v1/realtime?intent=transcription`) | 一把 OpenAI Key 同时完成识别和翻译 |
| **流式上下文翻译** | **DeepSeek（推荐）** | `deepseek-chat` (SSE Stream) | 中文翻译自然、性价比极高 |
| **流式上下文翻译** | **OpenAI** | `gpt-4.1-mini` (SSE Stream) | 响应稳定，与 OpenAI 识别共用同一密钥 |

> 翻译目标支持 47 种语言（默认简体中文），也支持「仅显示实时原文」模式（不产生任何翻译请求）。

## 安装和使用

1. 下载并解压本扩展目录（或直接克隆本仓库）。需要桌面版 Chrome 116 及以上版本。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启右上角**开发者模式**，点击**加载已解压的扩展程序**，选择包含 `manifest.json` 的文件夹。
3. 打开任意正在播放的 YouTube 直播或视频页面，点击工具栏上的「YouTube 双语直播字幕」图标：
   - 选择流式语音识别引擎（推荐 **Deepgram Nova-3**，或 **OpenAI Realtime**）并填入密钥。
   - 如已知主播语种（例如英语/日语/韩语），可在「直播原语」里指定，能显著提升嘈杂游戏直播下的识别准确率；默认「自动检测（多语言）」。
   - 选择翻译引擎（推荐 **DeepSeek**，或 **OpenAI**）并填入密钥（若识别与翻译均选 OpenAI，只需填一次）。
   - 点击**启动实时字幕**。
4. 字幕会直接叠加在 YouTube 播放器下方（全屏同样有效）。鼠标悬停在字幕上可：
   - 按住 `⋮⋮ 拖动` 上下调整位置
   - 点击 `A-` / `A+` 调整字号（自动记住偏好）
   - 点击 `记录` 展开右侧双语历史记录面板并一键复制
   - 点击 `停止` 直接结束本次识别

## 隐私与密钥

- API 密钥仅保存在你本机的 Chrome 扩展本地存储中（`chrome.storage.local`），方便下次一键启动，也可随时在弹窗右下角点击「清除密钥」彻底删除。
- 音频流和待翻译文本仅直接发送到你所选择的 Deepgram / OpenAI / DeepSeek 官方接口，不经过任何第三方中转服务器。
